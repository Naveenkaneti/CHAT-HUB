# Global Multi-User Chat Platform

A professional, scalable real-time chat application built with the MERN stack (MongoDB, Express, React, Node.js) and Socket.io.

## Project Structure

- `chat-app-frontend/`: Vite-powered React application with a premium gradient UI and interactive animations.
- `chat-app-backend/`: Node.js/Express server handling authentication, real-time messaging, and user management.

## Key Features

- **Real-time Messaging**: Instant communication using Socket.io.
- **Modern UI**: Premium design with glassmorphism, gradients, and smooth micro-animations.
- **Authentication**: Secure JWT-based session management.
- **User Discovery**: Real-time discovery of online users.
- **Admin Console**: Robust management system for users and sessions.

## Setup Instructions

### Backend
1. `cd chat-app-backend`
2. `npm install`
3. Create a `.env` file with your credentials (MONGO_URI, JWT_SECRET, etc.).
4. `npm run dev`

### Frontend
1. `cd chat-app-frontend`
2. `npm install`
3. `npm run dev`
